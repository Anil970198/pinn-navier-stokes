# Depth from CLIP Text-Image Gradient Alignment

## Abstract
This project exploits the latent spatial understanding of a frozen Contrastive Language-Image Pretraining (CLIP) Vision Transformer (ViT). CLIP is trained purely for global image-text matching and receives no depth or continuous spatial supervision. However, to distinguish depth-dependent language prompts (e.g., `"a close up photograph"` vs. `"a wide angle landscape"`), the ViT encoder must implicitly learn to separate foreground from background. This project extracts that learned geometric signal using structural model surgery—specifically through inference-time backpropagation and intermediate patch-token projection—yielding zero-shot monocular depth estimation.

## Methodology

This repository implements two independent mathematical approaches to extract depth without training or labels:

### 1. The Gradient Method (Backprop as a Spatial Query)
Instead of using backpropagation to update weights, we use the `autograd` engine at inference time as an architectural query tool. By calculating the cosine similarity of the input image against a depth-oriented text prompt, we compute the gradient map $\partial \text{Sim} / \partial x$. This mathematically reveals which spatial regions in the image satisfy the concept of "close" or "far."
To avoid the $32\times32$ blocky grid artifacts generated by raw pixel gradients in a ViT, we utilize PyTorch hooks (`register_forward_hook`) on `vision_model.embeddings.patch_embedding`. This intercepts the gradients precisely after the pixel-to-patch `Conv2d` projection, allowing us to extract gradients in the ViT's native topological space.

### 2. The Patch-Token Method
This method bypasses gradients entirely by directly extracting the `last_hidden_state` of the ViT (omitting the `[CLS]` token). The remaining patch tokens are manually passed through the `visual_projection` layer, bringing individual spatial patches into the shared text-image hyperspace. We then compute cosine similarity patch-by-patch against the text embeddings to generate a coarse topological map.

## Scientific Proof: Layer-Wise Depth Evolution

To mathematically demonstrate that this geometric signal is not a superficial color-correlation artifact or dataset center-bias, the repository includes an internal architectural probe (`layer_evolution.py`).
By extracting the intermediate token representations from every single hidden Transformer layer (0 through 12) and projecting them into the contrastive text space, we visualize the temporal evolution of the model's spatial reasoning. Visualizing these states proves that early layers contain purely structural noise, and the semantic concept of physical "depth" only crystallizes deep within the network's self-attention layers after extensive spatial-contextual integration.

## Usage

### Prerequisites
```bash
pip install torch transformers pillow opencv-python matplotlib scipy
```

### Depth Extraction Pipeline
Extract the combined depth map from an input image:
```bash
python main.py <path_to_image> --output_dir results
```
**Outputs Generated:**
- `01_main_strip.png`: Gradient heatmaps for "close" vs "far" prompts.
- `02_method_comparison.png`: Verification comparison between the Gradient and Patch-Token methods.
- `03_prompt_analysis.png`: Depth signal stability across multiple contrasting paired text embeddings.
- `04_depth_overlay.png`: The final combined zero-shot depth map structurally overlaid on the original image.
- `05_patch_grid.png`: Raw $7\times7$ patch-level similarity maps.

### Internal Layer-Wise Probe
Sequence the semantic depth extraction across all 12 hidden layers of the Vision Transformer to verify representational emergence:
```bash
python layer_evolution.py <path_to_image> --output_dir results
```
**Outputs Generated:**
- `06_layer_evolution.png`: A sequence of 13 visual states proving the hierarchical emergence of architectural depth.
